# Coastal Tree Experts — Website Concept

Redesign concept by [TD Creatives](https://tdcreativesagency.com) for Coastal Tree Experts Inc, Morro Bay, CA.

## Contents
- `index.html` — the complete site (homepage + free-quote page in one file, hash-routed)

## Deploy on GitHub Pages
1. Upload `index.html` (and this README) to the repo root
2. Settings → Pages → Source: `main` branch, `/ (root)` folder
3. Live at `https://<username>.github.io/<repo>/`
4. Direct link to the quote form: append `#/quote`

## Notes
- Logo is embedded in the file; gallery photos load from the client's current live site
- The quote form is a visual demo — it does not submit anywhere yet
